# Tech Stack

## Core Technologies
- **Framework**: [Next.js](https://nextjs.org/) (Version 16.2.7) - App Router
- **Language**: TypeScript
- **UI Library**: React (Version 19)

## Database & Backend
- **Database**: PostgreSQL (via Supabase)
- **Backend as a Service (BaaS)**: [Supabase](https://supabase.com/)
- **ORM / Client**: `@supabase/supabase-js`, `@supabase/ssr`

## Styling & UI Components
- **Styling**: Tailwind CSS (Version 4)
- **Icons**: `lucide-react`
- **Component Utilities**: `clsx`, `tailwind-merge`, `class-variance-authority`
- **Fonts**: Geist, Geist Mono (via `next/font/google`)
- **Forms/Select**: `react-select`

## Utilities & Third-Party Services
- **Date Formatting**: `date-fns`
- **Email Service**: [Resend](https://resend.com/)

## Development Tools
- **Linting**: ESLint
- **Type Checking**: TypeScript

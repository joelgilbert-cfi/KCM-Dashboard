# Project Overview

## Purpose and Domain
The KCM (Kitchen Closure Management) Dashboard is an internal centralised tool used by Business Finance and Expansion teams to manage the lifecycle of kitchen closures. It tracks kitchen statuses across various clusters, manages fixed assets (FAR), closure requests, and audit logs. 

## Key Features
- **Cluster & Kitchen Management**: Track active, under closure, and closed kitchens.
- **Closure Tracking**: Detailed financial and operational tracker for the closure process.
- **Fixed Asset Register (FAR)**: Track asset conditions, movements, and sales.
- **Closure Requests**: Generate and manage closure requests (including email dispatch via Resend).
- **Role-Based Access Control (RBAC)**: Distinct permissions for `admin`, `finance`, and `expansion` roles.
- **Audit Logging**: Comprehensive logging of data changes.

## Target Audience
- **Finance Team**: Views operational data, manages financial aspects (FAR, closure requests).
- **Expansion Team**: Manages operational aspects (clusters, kitchens, closure tracker, asset movements/sales).
